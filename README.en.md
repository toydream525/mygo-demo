## ✨ Highlights

> [!NOTE]
> **Unofficial Fan Project:** Single-player fan web game with no accounts, payments, or online multiplayer. All original characters and franchise IP belong to their respective copyright holders. Asset, voice, and AI model sources & licenses are documented in [ASSETS.md](ASSETS.md). Character AI strategies and additional lines are fan-authored.

| Feature | Details |
| :--- | :--- |
| **🃏 Three Card Games** | Full matches against character AI in **Dou Dizhu (Fight the Landlord)**, **Pao De Kuai (Run Fast)**, and **Blackjack** |
| **🎸 10 Band Members** | Play as any of the 10 members grouped by **MyGO!!!!!** and **Ave Mujica** |
| **🎨 Dual Band Themes & Wardrobe** | Two dedicated band UI themes, character outfit wardrobe, and custom card art |
| **🎙️ Japanese Voices & Table Reactions** | Character voice lines, expression/scene variations, and concurrent table banter |
| **⚡ Difficulty & Character Skills** | Adjustable difficulty, move hints, and auto-play; Dou Dizhu offers both Classic and Character Skill modes |
| **📱 Desktop & Mobile Landscape** | Responsive desktop and mobile landscape support, browser fullscreen, and local score/preference persistence |

## 🚀 Local Development & Build

**Prerequisites:** Node.js `20.19+` or `22.12+`.

```sh
# 1. Install dependencies
npm install

# 2. Start dev server
npm run dev
```

Open the URL printed in your terminal to play.

```sh
# Run tests
npm test

# Build static production bundle (outputs to dist/)
npm run build

# Preview production build locally
npm run preview
```

> Release archives bundle the source code, runtime assets, and prebuilt static files.
